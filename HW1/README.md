# Вендинговый автомат

Консольное приложение на C# для эмуляции работы вендингового автомата.

## Функции

- Просмотр товаров и цен
- Вставка монет разных номиналов  
- Покупка товаров
- Выдача сдачи
- Возврат неиспользованных монет
- Администраторский режим (пополнение товаров, сбор денег)

## Запуск

```bash
dotnet run
```
